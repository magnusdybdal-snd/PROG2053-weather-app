# Explore Nature

A multi-page website built for NTNU's PROG2053 course, showcasing dynamic content loading with vanilla JavaScript.

## Features

- Live weather for 10 major cities worldwide, fetched from the Open-Meteo API and displayed with condition icons
- Infinite-scroll post feed that fetches and renders posts dynamically as the user scrolls
- Responsive, hand-crafted HTML/CSS layout across Home, Posts, and Weather pages

## Tech Stack

- HTML5 / CSS3
- Vanilla JavaScript (Fetch API)
- [Open-Meteo](https://open-meteo.com/) weather API
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) for mock post data

## Running the Project

Open `oblig1main.html` in a browser, or serve the folder with any static file server.
